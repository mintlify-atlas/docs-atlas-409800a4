## Get Company Wallets

Retrieve a paginated list of all company wallets with optional currency filtering.

<Note>
This endpoint requires admin authorization.
</Note>

```bash
GET /api/admin/wallets/companies
```

### Query Parameters

<ParamField query="currency" type="string">
  Filter wallets by currency code (e.g., SAR, EGP) or symbol. Optional.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination. Automatically adjusted to 1 if less than 1.
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Number of items per page. Must be between 1 and 100 (defaults to 20 if outside range).
</ParamField>

### Response Fields

<ResponseField name="wallets" type="array">
  Array of company wallet items
  
  <Expandable title="wallet object">
    <ResponseField name="companyId" type="string" required>
      Company's unique ID
    </ResponseField>
    
    <ResponseField name="companyName" type="string" required>
      Company's name (defaults to "غير معروف" if unavailable)
    </ResponseField>
    
    <ResponseField name="logoUrl" type="string">
      Company's logo URL
    </ResponseField>
    
    <ResponseField name="currency" type="string" required>
      Wallet currency code (SAR, EGP, etc.)
    </ResponseField>
    
    <ResponseField name="walletBalance" type="decimal" required>
      Current available balance in wallet
    </ResponseField>
    
    <ResponseField name="totalEarnings" type="decimal" required>
      Lifetime earnings from bookings
    </ResponseField>
    
    <ResponseField name="totalCommission" type="decimal" required>
      Total commission deducted
    </ResponseField>
    
    <ResponseField name="netProfit" type="decimal" required>
      Net profit (earnings - commission)
    </ResponseField>
    
    <ResponseField name="totalDeposits" type="decimal" required>
      Total amount deposited to wallet
    </ResponseField>
    
    <ResponseField name="totalWithdrawals" type="decimal" required>
      Total amount withdrawn from wallet
    </ResponseField>
    
    <ResponseField name="lastUpdatedAt" type="datetime">
      Timestamp of last wallet update
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="totalCount" type="integer">
  Total number of company wallets
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="pageSize" type="integer">
  Items per page
</ResponseField>

<ResponseField name="totalPages" type="integer">
  Total pages available
</ResponseField>

### Example Request

```bash
curl -X GET "https://api.masareagle.sa/api/admin/wallets/companies?currency=SAR&page=1&pageSize=20" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

      "walletBalance": 45000.00,

## Get Company Wallet Transactions

Retrieve paginated transaction history for a specific company wallet.

```bash
GET /api/admin/wallets/companies/{companyId}/transactions
```

### Path Parameters

<ParamField path="companyId" type="string" required>
  The company's unique ID
</ParamField>

### Query Parameters

<ParamField query="currency" type="string" required>
  Currency code for the wallet (SAR, EGP, etc.)
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="pageSize" type="integer" default="10">
  Number of transactions per page (1-100)
</ParamField>

### Response Fields

<ResponseField name="transactions" type="array">
  Array of wallet transactions
  
  <Expandable title="transaction object">
    <ResponseField name="id" type="string" required>
      Transaction unique ID
    </ResponseField>
    
    <ResponseField name="transactionType" type="string" required>
      Transaction type code (Deposit, Withdraw, Deduct, Add, Refund, Commission, Settlement)
    </ResponseField>
    
    <ResponseField name="transactionTypeDisplay" type="string" required>
      Arabic display name for transaction type
    </ResponseField>
    
    <ResponseField name="amount" type="decimal" required>
      Transaction amount
    </ResponseField>
    
    <ResponseField name="balanceBefore" type="decimal" required>
      Wallet balance before transaction
    </ResponseField>
    
    <ResponseField name="balanceAfter" type="decimal" required>
      Wallet balance after transaction
    </ResponseField>
    
    <ResponseField name="referenceId" type="string">
      Reference to related entity (booking ID, transfer ID, etc.)
    </ResponseField>
    
    <ResponseField name="referenceType" type="string">
      Type of reference (Booking, Transfer, etc.)
    </ResponseField>
    
    <ResponseField name="performedBy" type="string">
      User ID who performed the transaction
    </ResponseField>
    
    <ResponseField name="performedByType" type="string">
      Type of performer (Admin, System, Company)
    </ResponseField>
    
    <ResponseField name="notes" type="string">
      Transaction notes or description
    </ResponseField>
    
    <ResponseField name="bankTransferReference" type="string">
      Bank transfer reference number if applicable
    </ResponseField>
    
    <ResponseField name="createdAtUtc" type="datetime" required>
      UTC timestamp when transaction was created
    </ResponseField>
    
    <ResponseField name="currency" type="string" required>
      Transaction currency code
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="totalCount" type="integer">
  Total number of transactions
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="pageSize" type="integer">
  Items per page
</ResponseField>

<ResponseField name="totalPages" type="integer">
  Total pages available
</ResponseField>

## Deposit to Company Wallet

Add funds to a company's wallet (admin operation).

```bash
POST /api/admin/companies/{companyId}/wallet/deposit
```

### Path Parameters

<ParamField path="companyId" type="string" required>
  The company's unique ID
</ParamField>

### Request Body

<ParamField body="amount" type="decimal" required>
  Amount to deposit. Must be positive.
</ParamField>

<ParamField body="currency" type="string" required>
  Currency code (SAR, EGP, etc.) or symbol
</ParamField>

<ParamField body="transferReference" type="string">
  Optional bank transfer or transaction reference number
</ParamField>

<ParamField body="notes" type="string">
  Optional admin notes for this deposit
</ParamField>

### Response Fields

<ResponseField name="success" type="boolean" required>
  Indicates if deposit was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  Success or error message in Arabic
</ResponseField>

<ResponseField name="newBalance" type="decimal">
  Company's new wallet balance after deposit
</ResponseField>

### Example Request

```bash
curl -X POST "https://api.masareagle.sa/api/admin/companies/company_789/wallet/deposit" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 10000.00,
    "currency": "SAR",
    "transferReference": "COMP-DEP-20260310",
    "notes": "Initial balance deposit"
  }'
```

### Example Response

```json
{
  "success": true,
  "message": "تم إيداع 10000.00 SAR بنجاح",
  "newBalance": 55000.00
}
```

<Info>
Company wallets are auto-created if they don't exist. A notification is sent to the company upon successful deposit.
</Info>

## Withdraw from Company Wallet

Withdraw funds from a company's wallet (admin operation).

```bash
POST /api/admin/companies/{companyId}/wallet/withdraw
```

### Path Parameters

<ParamField path="companyId" type="string" required>
  The company's unique ID
</ParamField>

### Request Body

<ParamField body="amount" type="decimal" required>
  Amount to withdraw. Must be positive and not exceed wallet balance.
</ParamField>

<ParamField body="currency" type="string" required>
  Currency code (SAR, EGP, etc.) or symbol
</ParamField>

<ParamField body="transferReference" type="string">
  Optional bank transfer or transaction reference number
</ParamField>

<ParamField body="notes" type="string">
  Optional admin notes for this withdrawal
</ParamField>

### Response Fields

<ResponseField name="success" type="boolean" required>
  Indicates if withdrawal was successful
</ResponseField>

<ResponseField name="message" type="string" required>
  Success or error message in Arabic
</ResponseField>

<ResponseField name="newBalance" type="decimal">
  Company's new wallet balance after withdrawal
</ResponseField>

### Example Request

```bash
curl -X POST "https://api.masareagle.sa/api/admin/companies/company_789/wallet/withdraw" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 5000.00,
    "currency": "SAR",
    "transferReference": "COMP-WD-20260310",
    "notes": "Company withdrawal request"
  }'
```

### Example Response

```json
{
  "success": true,
  "message": "تم سحب 5000.00 SAR بنجاح",
  "newBalance": 50000.00
}
```

### Error Response

```json
{
  "success": false,
  "message": "رصيد غير كافي",
  "newBalance": null
}
```

<Warning>
Withdrawals will fail if the amount exceeds the available wallet balance. A withdrawal notification is sent to the company upon success.
</Warning>
