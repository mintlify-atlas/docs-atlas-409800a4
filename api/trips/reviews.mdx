## Create Driver Review

Passengers can rate and review drivers after completing a trip.

<CodeGroup>
```bash cURL
curl -X POST "https://api.masareagles.com/api/trips/{tripId}/driver-review" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "driverId": "drv_xyz789",
    "passengerId": "psng_abc123",
    "rating": 5,
    "comment": "Excellent driver, very professional and punctual"
  }'
```
</CodeGroup>

### Endpoint

<ParamField path="method" type="string" required>
  POST
</ParamField>

<ParamField path="url" type="string" required>
  `/api/trips/{tripId}/driver-review`
</ParamField>

<ParamField path="tripId" type="string" required>
  Trip identifier
</ParamField>

### Request Body

<ParamField body="driverId" type="string" required>
  Driver identifier being reviewed
</ParamField>

<ParamField body="passengerId" type="string" required>
  Passenger identifier submitting the review
</ParamField>

<ParamField body="rating" type="integer" required>
  Rating from 1 to 5 stars
</ParamField>

<ParamField body="comment" type="string">
  Optional review comment
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  Indicates if review was created successfully
</ResponseField>

<ResponseField name="message" type="string">
  Success or error message in Arabic
</ResponseField>

<ResponseField name="reviewId" type="string">
  Unique review identifier
</ResponseField>

<ResponseField name="rating" type="decimal">
  The submitted rating
</ResponseField>

<ResponseField name="averageRating" type="decimal">
  Driver's updated average rating
</ResponseField>

<ResponseField name="totalReviews" type="integer">
  Driver's total review count
</ResponseField>

<ResponseExample>
```json Success Response
{
  "success": true,
  "message": "تم إضافة التقييم بنجاح",
  "reviewId": "rev_abc123xyz",
  "rating": 5,
  "averageRating": 4.8,
  "totalReviews": 128
}
```

```json Error - Already Reviewed
{
  "success": false,
  "message": "لقد قمت بتقييم هذا السائق مسبقاً"
}
```

```json Error - No Confirmed Booking
{
  "success": false,
  "message": "يجب أن يكون لديك حجز مؤكد لتقييم السائق"
}
```
</ResponseExample>

## Get Driver Reviews

Retrieve all reviews for a specific driver with optional pagination.

<CodeGroup>
```bash cURL - All Reviews
curl -X GET "https://api.masareagles.com/api/drivers/{driverId}/reviews" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash cURL - Paginated
curl -X GET "https://api.masareagles.com/api/drivers/{driverId}/reviews?page=1&pageSize=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

### Endpoint

<ParamField path="method" type="string" required>
  GET
</ParamField>

<ParamField path="url" type="string" required>
  `/api/drivers/{driverId}/reviews`
</ParamField>

<ParamField path="driverId" type="string" required>
  Driver identifier
</ParamField>

### Query Parameters

<ParamField query="page" type="integer">
  Page number for pagination (default: 1)
</ParamField>

<ParamField query="pageSize" type="integer">
  Number of results per page (default: 20)
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  Indicates if request succeeded
</ResponseField>

<ResponseField name="message" type="string">
  Result message
</ResponseField>

<ResponseField name="reviews" type="array">
  Array of review objects
  
  <Expandable title="Review Object">
    <ResponseField name="id" type="string">
      Review identifier
    </ResponseField>
    
    <ResponseField name="tripId" type="string">
      Associated trip ID
    </ResponseField>
    
    <ResponseField name="passengerId" type="string">
      Passenger who wrote the review
    </ResponseField>
    
    <ResponseField name="passengerName" type="string">
      Passenger name
    </ResponseField>
    
    <ResponseField name="passengerImage" type="string">
      Passenger profile image URL
    </ResponseField>
    
    <ResponseField name="rating" type="integer">
      Rating (1-5)
    </ResponseField>
    
    <ResponseField name="comment" type="string">
      Review comment
    </ResponseField>
    
    <ResponseField name="createdAtUtc" type="string">
      Review creation timestamp
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="totalReviews" type="integer">
  Total number of reviews
</ResponseField>

<ResponseField name="averageRating" type="decimal">
  Driver's average rating
</ResponseField>

<ResponseField name="ratingDistribution" type="object">
  Breakdown of ratings by star count
  
  <Expandable title="Rating Distribution">
    <ResponseField name="fiveStars" type="integer">
      Count of 5-star reviews
    </ResponseField>
    
    <ResponseField name="fourStars" type="integer">
      Count of 4-star reviews
    </ResponseField>
    
    <ResponseField name="threeStars" type="integer">
      Count of 3-star reviews
    </ResponseField>
    
    <ResponseField name="twoStars" type="integer">
      Count of 2-star reviews
    </ResponseField>
    
    <ResponseField name="oneStar" type="integer">
      Count of 1-star reviews
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="pageSize" type="integer">
  Results per page
</ResponseField>

## Delete Review

Delete a review (admin or review author only).

<CodeGroup>
```bash cURL - Driver Review
curl -X DELETE "https://api.masareagles.com/api/driver-reviews/{reviewId}" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash cURL - Passenger Review
curl -X DELETE "https://api.masareagles.com/api/passenger-reviews/{reviewId}" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash cURL - Company Review
curl -X DELETE "https://api.masareagles.com/api/company-reviews/{reviewId}" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

### Endpoints

- `/api/driver-reviews/{reviewId}` - Delete driver review
- `/api/passenger-reviews/{reviewId}` - Delete passenger review
- `/api/company-reviews/{reviewId}` - Delete company review

### Response

<ResponseField name="success" type="boolean">
  Indicates if deletion succeeded
</ResponseField>

<ResponseField name="message" type="string">
  Result message
</ResponseField>

<ResponseExample>
```json Success Response
{
  "success": true,
  "message": "تم حذف التقييم بنجاح"
}
```
</ResponseExample>
