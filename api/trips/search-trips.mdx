## Unified Trip Search

Search for available trips across both driver-created trips and company trips. Returns a unified list with trip type discriminators.

<CodeGroup>
```bash cURL - Basic Search
curl -X GET "https://api.masareagles.com/api/trips/search/unified?from=Riyadh&to=Jeddah&dateFrom=2026-03-15T00:00:00Z" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash cURL - Advanced Search
curl -X GET "https://api.masareagles.com/api/trips/search/unified?from=Riyadh&to=Jeddah&dateFrom=2026-03-15T00:00:00Z&dateTo=2026-03-16T23:59:59Z&minPrice=50&maxPrice=200&requiredSeats=2&tripType=all" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```bash cURL - Company Trips Only
curl -X GET "https://api.masareagles.com/api/trips/search/unified?from=Makkah&to=Madinah&tripType=company" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

### Endpoint

<ParamField path="method" type="string" required>
  GET
</ParamField>

<ParamField path="url" type="string" required>
  `/api/trips/search/unified`
</ParamField>

### Query Parameters

<ParamField query="from" type="string">
  Origin city or location name to filter trips
</ParamField>

<ParamField query="to" type="string">
  Destination city or location name to filter trips
</ParamField>

<ParamField query="dateFrom" type="string">
  Start of date range for trip departure (ISO 8601 format)
</ParamField>

<ParamField query="dateTo" type="string">
  End of date range for trip departure (ISO 8601 format)
</ParamField>

<ParamField query="minPrice" type="decimal">
  Minimum price filter
</ParamField>

<ParamField query="maxPrice" type="decimal">
  Maximum price filter
</ParamField>

<ParamField query="requiredSeats" type="integer">
  Minimum number of available seats required
</ParamField>

<ParamField query="tripType" type="string">
  Filter by trip type:
  - `driver` - Only driver-created trips
  - `company` - Only company trips
  - `all` - Both types (default)
</ParamField>

## Legacy Search Trips

Search for driver trips only (legacy endpoint). For unified search including company trips, use the Unified Trip Search endpoint above.

<CodeGroup>
```bash cURL
curl -X GET "https://api.masareagles.com/api/trips/search?from=Riyadh&to=Dammam&dateFrom=2026-03-15T00:00:00Z&minPrice=50&maxPrice=200" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
</CodeGroup>

<ParamField path="method" type="string" required>

</ParamField>

<ParamField path="url" type="string" required>

</ParamField>

<ParamField query="from" type="string">

</ParamField>

<ParamField query="to" type="string">

<ParamField query="dateFrom" type="string">

</ParamField>

<ParamField query="dateTo" type="string">

</ParamField>

<ParamField query="minPrice" type="decimal">
  Minimum price filter
</ParamField>

<ParamField query="maxPrice" type="decimal">
