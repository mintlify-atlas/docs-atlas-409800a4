## Overview

The Companies API provides endpoints for managing company profiles, credentials, drivers, vehicles, and public information. Companies can manage their own profiles while admins have full access to all company operations.

## Authentication

Most endpoints require authentication. Include the JWT token in the Authorization header:

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

---

## Get Company Profile

<api-endpoint method="GET" endpoint="/api/company/profile" />

Get the current authenticated company's profile information. **Company role required**.

### Response

<ResponseField name="Id" type="string">
  Company unique identifier
</ResponseField>

<ResponseField name="Email" type="string">
  Company email address
</ResponseField>

<ResponseField name="Name" type="string" nullable>
  Company name
</ResponseField>

<ResponseField name="PhoneNumber" type="string" nullable>
  Company phone number
</ResponseField>

<ResponseField name="LogoUrl" type="string" nullable>
  URL to company logo
</ResponseField>

<ResponseField name="Address" type="string" nullable>
  Company physical address
</ResponseField>

<ResponseField name="CommercialRegistrationNumber" type="string" nullable>
  Commercial registration number
</ResponseField>

<ResponseField name="IsActive" type="boolean">
  Whether company account is active
</ResponseField>

<ResponseField name="IsProfileComplete" type="boolean">
  Whether profile is complete (requires Name and PhoneNumber)
</ResponseField>

<ResponseField name="LastLoginAt" type="datetime" nullable>
  Last login timestamp
</ResponseField>

<ResponseField name="CreatedAt" type="datetime">
  Account creation timestamp
</ResponseField>

### Example Request

```bash
curl -X GET "https://api.masareagles.com/api/company/profile" \
  -H "Authorization: Bearer YOUR_COMPANY_JWT_TOKEN"
```

### Example Response

```json
{
  "Id": "c_345678",
  "Email": "info@transportco.com",
  "Name": "شركة النقل المتطور",
  "PhoneNumber": "+966112345678",
  "LogoUrl": "/uploads/companies/c_345678/logo.png",
  "Address": "الرياض، شارع الملك فهد",
  "CommercialRegistrationNumber": "1234567890",
  "IsActive": true,
  "IsProfileComplete": true,
  "LastLoginAt": "2024-03-10T10:00:00Z",
  "CreatedAt": "2024-01-01T00:00:00Z"
}
```

## Update Company Profile

<api-endpoint method="PUT" endpoint="/api/company/profile" />

Update company profile information. **Company role required**.

### Request Body

<ParamField body="Name" type="string" optional>
  Company name (max 200 characters)
</ParamField>

<ParamField body="PhoneNumber" type="string" optional>
  Company phone number (digits, spaces, +, -, () allowed)
</ParamField>

<ParamField body="Address" type="string" optional>
  Company address (max 500 characters)
</ParamField>

<ParamField body="CommercialRegistrationNumber" type="string" optional>
  Commercial registration number (max 50 characters)
</ParamField>

### Response

Returns the same structure as Get Company Profile with updated values.

### Example Request

```bash
curl -X PUT "https://api.masareagles.com/api/company/profile" \
  -H "Authorization: Bearer YOUR_COMPANY_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "Name": "شركة النقل المتطور للنقل",
    "PhoneNumber": "+966112345678",
    "Address": "الرياض، المملكة العربية السعودية",
    "CommercialRegistrationNumber": "1234567890"
  }'
```

## Upload Company Logo

<api-endpoint method="POST" endpoint="/api/company/logo" />

Upload or update company logo. **Company role required**.

### Request Body (Form Data)

<ParamField body="Logo" type="file" required>
  Image file (JPEG, PNG, WebP - max 5MB, recommended: 512x512px)
</ParamField>

### Response

<ResponseField name="LogoUrl" type="string">
  URL to the uploaded logo
</ResponseField>

<ResponseField name="Message" type="string">
  Success message
</ResponseField>

### Example Request

```bash
curl -X POST "https://api.masareagles.com/api/company/logo" \
  -H "Authorization: Bearer YOUR_COMPANY_JWT_TOKEN" \
  -F "Logo=@company-logo.png"
```

## Update Company Credentials

<api-endpoint method="PUT" endpoint="/api/company/credentials" />

Update company email and/or password. **Company role required**.

### Request Body

<ParamField body="Email" type="string" optional>
  New email address (valid email format)
</ParamField>

<ParamField body="CurrentPassword" type="string" required>
  Current password for verification
</ParamField>

<ParamField body="NewPassword" type="string" optional>
  New password (min 8 characters, requires uppercase, lowercase, digit, special char)
</ParamField>

### Response

<ResponseField name="Message" type="string">
  Success message
</ResponseField>

<ResponseField name="Email" type="string">
  Updated email address
</ResponseField>

### Example Request

```bash
curl -X PUT "https://api.masareagles.com/api/company/credentials" \
  -H "Authorization: Bearer YOUR_COMPANY_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "Email": "newemail@transportco.com",
    "CurrentPassword": "OldPassword123!",
    "NewPassword": "NewSecurePass456!"
  }'
```

## Error Responses

All endpoints may return the following error responses:

### Common Error Codes

- `400 Bad Request` - Invalid request or validation errors
- `401 Unauthorized` - Missing or invalid authentication
- `403 Forbidden` - Insufficient permissions
- `404 Not Found` - Company not found
- `500 Internal Server Error` - Server error

### Example Error Response

```json
{
  "error": "فشل التحقق من البيانات",
  "details": [
    "اسم الشركة يجب أن لا يتجاوز 200 حرف"
  ]
}
```
