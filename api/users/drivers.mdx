## Overview

The Drivers API provides comprehensive endpoints for managing driver profiles, registration workflows, document verification, and status management. All authenticated endpoints require a valid JWT token.

## Authentication

All endpoints except `Get Driver by ID` require authentication. Include the JWT token in the Authorization header:

```bash
Authorization: Bearer YOUR_JWT_TOKEN
```

---

## List Drivers

<api-endpoint method="GET" endpoint="/api/drivers" />

Retrieve a paginated list of all drivers with search functionality. **Admin only**.

### Query Parameters

<ParamField query="Page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="PageSize" type="integer" default="20">
  Number of items per page (max 100)
</ParamField>

<ParamField query="SearchTerm" type="string" optional>
  Search by phone number or full name
</ParamField>

<ParamField query="IncludeDeleted" type="boolean" default="false">
  Include soft-deleted drivers in results
</ParamField>

### Response

<ResponseField name="Drivers" type="array">
  List of driver summaries
  <expandable>
    <ResponseField name="Id" type="string">
      Driver unique identifier
    </ResponseField>
    <ResponseField name="PhoneNumber" type="string">
      Driver's phone number
    </ResponseField>
    <ResponseField name="FullName" type="string" nullable>
      Driver's full name
    </ResponseField>
    <ResponseField name="ProfilePictureUrl" type="string" nullable>
      URL to profile picture
    </ResponseField>
    <ResponseField name="IsPhoneVerified" type="boolean">
      Whether phone is verified
    </ResponseField>
    <ResponseField name="IsProfileComplete" type="boolean">
      Whether profile is complete
    </ResponseField>
    <ResponseField name="IsRegistrationComplete" type="boolean">
      Whether registration is complete
    </ResponseField>
    <ResponseField name="IsActive" type="boolean">
      Whether driver is active
    </ResponseField>
    <ResponseField name="VehicleCount" type="integer">
      Number of vehicles owned
    </ResponseField>
    <ResponseField name="CreatedAt" type="datetime">
      Account creation timestamp
    </ResponseField>
    <ResponseField name="LastLoginAt" type="datetime" nullable>
      Last login timestamp
    </ResponseField>
  </expandable>
</ResponseField>

<ResponseField name="TotalCount" type="integer">
  Total number of drivers matching criteria
</ResponseField>

<ResponseField name="Page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="PageSize" type="integer">
  Items per page
</ResponseField>

<ResponseField name="TotalPages" type="integer">
  Total number of pages
</ResponseField>

### Example Request

```bash
curl -X GET "https://api.masareagles.com/api/drivers?Page=1&PageSize=20&SearchTerm=966" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### Example Response

## Complete/Update Driver Profile

<api-endpoint method="PUT" endpoint="/api/drivers/profile/complete-and-update" />

Complete or update driver profile with personal information and document uploads. Supports multipart/form-data for file uploads.

### Request Body (Form Data)

<ParamField body="FullName" type="string" optional>
  Driver's full name (2-100 characters)
</ParamField>

<ParamField body="DateOfBirth" type="date" optional>
  Date of birth (driver must be 18-70 years old)
</ParamField>

<ParamField body="IdentityDocument" type="file" optional>
  Identity document image (JPEG, PNG, PDF - max 10MB)
</ParamField>

<ParamField body="DrivingLicense" type="file" optional>
  Driving license image (JPEG, PNG, PDF - max 10MB)
</ParamField>

<ParamField body="DeleteIdentityDocument" type="boolean" default="false">
  Set to true to delete existing identity document
</ParamField>

<ParamField body="DeleteDrivingLicense" type="boolean" default="false">
  Set to true to delete existing driving license
</ParamField>

### Response

<ResponseField name="Id" type="string">
  Driver ID
</ResponseField>

<ResponseField name="FullName" type="string" nullable>
  Updated full name
</ResponseField>

<ResponseField name="DateOfBirth" type="date" nullable>
  Updated date of birth
</ResponseField>

<ResponseField name="IdentityDocumentUrl" type="string" nullable>
  URL to identity document
</ResponseField>

<ResponseField name="DrivingLicenseUrl" type="string" nullable>
  URL to driving license
</ResponseField>

<ResponseField name="IsProfileComplete" type="boolean">
  Profile completion status
</ResponseField>

<ResponseField name="Message" type="string">
  Success message
</ResponseField>

<ResponseField name="VerificationStatus" type="string">
  Current verification status
</ResponseField>

<ResponseField name="Progress" type="number">
  Profile completion progress percentage
</ResponseField>

<ResponseField name="FieldStatuses" type="array">
  Status of each profile field
</ResponseField>

### Example Request

```bash
curl -X PUT "https://api.masareagles.com/api/drivers/profile/complete-and-update" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "FullName=أحمد محمد" \
  -F "DateOfBirth=1990-05-15" \
  -F "IdentityDocument=@identity.jpg" \
  -F "DrivingLicense=@license.jpg"
```

## Error Responses

All endpoints may return the following error responses:

<ResponseField name="error" type="string">
  Error message in Arabic or English
</ResponseField>

### Common Error Codes

- `400 Bad Request` - Invalid request parameters or validation errors
- `401 Unauthorized` - Missing or invalid authentication token
- `403 Forbidden` - Insufficient permissions
- `404 Not Found` - Driver not found
- `500 Internal Server Error` - Server error

### Example Error Response

```json
{
  "error": "لم يتم العثور على السائق"
}
```
