## Overview

Admin user management APIs enable administrators to create, update, and manage user accounts including companies, drivers, and their verification status. All endpoints require admin authorization.

## List Companies

Retrieve a paginated list of companies with search and filtering capabilities.

<CodeGroup>
```bash cURL
curl -X GET "https://api.masareagle.com/api/admin/companies?page=1&pageSize=20" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```
</CodeGroup>

### Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Number of results per page
</ParamField>

<ParamField query="search" type="string" optional>
  Search by company name or email
</ParamField>

### Response

<ResponseField name="items" type="array">
  Array of company objects
  <expandable>
    <ResponseField name="id" type="string">
      Company identifier
    </ResponseField>
    <ResponseField name="name" type="string">
      Company name
    </ResponseField>
    <ResponseField name="email" type="string">
      Company email address
    </ResponseField>
    <ResponseField name="logoUrl" type="string">
      Company logo URL
    </ResponseField>
    <ResponseField name="isActive" type="boolean">
      Whether the company is active
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      Creation timestamp
    </ResponseField>
  </expandable>
</ResponseField>

<ResponseField name="totalCount" type="integer">
  Total number of companies
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="pageSize" type="integer">
  Results per page
</ResponseField>

## Create Company

Create a new company account. Login credentials are sent via email.

<CodeGroup>
```bash cURL
curl -X POST "https://api.masareagle.com/api/admin/companies" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "company@example.com",
    "password": "SecurePass123!",
    "name": "Premium Transport Co.",
    "note": "VIP client - priority support"
  }'
```
</CodeGroup>

### Body Parameters

<ParamField body="email" type="string" required>
  Company email address (used for login)
</ParamField>

<ParamField body="password" type="string" required>
  Initial password for the company account
</ParamField>

<ParamField body="name" type="string" optional>
  Company name
</ParamField>

<ParamField body="note" type="string" optional>
  Admin notes about the company
</ParamField>

### Response

<ResponseField name="id" type="string">
  Created company identifier
</ResponseField>

<ResponseField name="email" type="string">
  Company email address
</ResponseField>

<ResponseField name="name" type="string">
  Company name
</ResponseField>

<ResponseField name="createdAt" type="string">
  Creation timestamp
</ResponseField>

## Driver Verification Reviews

### List Driver Reviews

Retrieve all drivers who have submitted their profile for verification review.

<CodeGroup>
```bash cURL
curl -X GET "https://api.masareagle.com/api/admin/driver-verification-reviews" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```
</CodeGroup>

### Response

<ResponseField name="reviews" type="array">
  Array of driver review summaries
  <expandable>
    <ResponseField name="driverId" type="string">
      Driver identifier
    </ResponseField>
    <ResponseField name="fullName" type="string">
      Driver full name
    </ResponseField>
    <ResponseField name="phoneNumber" type="string">
      Driver phone number
    </ResponseField>
    <ResponseField name="profilePictureUrl" type="string">
      Driver profile picture URL
    </ResponseField>
    <ResponseField name="verificationStatus" type="string">
      Current verification status (UnderReview, ActionNeeded)
    </ResponseField>
    <ResponseField name="progress" type="number">
      Profile completion progress (0-100)
    </ResponseField>
    <ResponseField name="hasBeenSubmittedBefore" type="boolean">
      Whether the driver has submitted before and needs to fix issues
    </ResponseField>
    <ResponseField name="lastUpdated" type="string">
      Last update timestamp
    </ResponseField>
  </expandable>
</ResponseField>

<Note>
This endpoint returns drivers with `UnderReview` or `ActionNeeded` verification status. These are the profiles that appear in the admin dashboard for verification.
</Note>

## Update Driver Review Field

Update the review status of a specific field in the driver's profile.

<CodeGroup>
```bash cURL
curl -X PATCH "https://api.masareagle.com/api/admin/driver-verification-reviews/{driverId}/fields/{field}" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "Approved",
    "notes": "All documents verified"
  }'
```
</CodeGroup>

### Path Parameters

<ParamField path="driverId" type="string" required>
  Driver identifier
</ParamField>

<ParamField path="field" type="string" required>
  Field name (PersonalInformation, IdentityDocument, DrivingLicense, VehicleInformation)
</ParamField>

### Body Parameters

<ParamField body="status" type="string" required>
  Review status (Approved, Rejected, PendingChanges)
</ParamField>

<ParamField body="notes" type="string" optional>
  Admin notes or feedback for the driver
</ParamField>

## Finalize Driver Review

Finalize the driver verification review and update their overall status.

<CodeGroup>
```bash cURL
curl -X POST "https://api.masareagle.com/api/admin/driver-verification-reviews/{driverId}/finalize" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "approved": true,
    "notes": "Driver approved - all documents valid"
  }'
```
</CodeGroup>

### Path Parameters

<ParamField path="driverId" type="string" required>
  Driver identifier
</ParamField>

### Body Parameters

<ParamField body="approved" type="boolean" required>
  Whether to approve the driver
</ParamField>

<ParamField body="notes" type="string" optional>
  Final notes for the driver
</ParamField>

<Note>
Finalizing a review will change the driver's verification status to either `Approved` or `ActionNeeded` depending on the decision.
</Note>
